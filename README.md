## About Me

<img align="right" width="320" src="https://ashensudaraka.com/images/profile/avatar.png" alt="Ashen Sudaraka" />

I design and develop **practical, intelligent software products** for the web, from intuitive user interfaces to scalable backends and reliable API services, with a growing focus on **cloud** and **AI/ML** technologies.

Turning concepts into solutions is my hobby, and I'm always updating my knowledge with new technologies to build high-quality products.

- Turning innovative ideas into creative solutions
- Passionate about problem solving and bug fixing
- Experienced in **MERN**, **Next.js** and **Java** development
- Exploring **AWS**, **Linux**, **CI/CD** and **AI/ML** with Python
- Currently pursuing a **BSc (Hons) in Software Engineering**
- Looking to collaborate on web development projects
- Based in **Pannala, Sri Lanka**
